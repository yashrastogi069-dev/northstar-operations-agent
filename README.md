# Northstar Operations Agent

Northstar is a deployable **LangGraph operations agent** for secure firm knowledge work. It uses guarded retrieval, a bounded tool registry, durable run state, human approval queues, workflow recovery, evaluations, and execution traces.

The agent can retrieve permitted firm knowledge, perform controlled public research, analyse structured information, produce an internal draft, and explain the evidence and tool path behind its work. It cannot execute unapproved external writes.

See [AGENT_ARCHITECTURE.md](./AGENT_ARCHITECTURE.md) for the graph, tool tiers, safety model, deployment model, and research basis. See [todo.md](./todo.md) for the build record.
